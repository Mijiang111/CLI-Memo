# Project

## Philosophy

- Keep the human view short, legible, and action-oriented.
- Give CLI agents a summary-first handoff with source refs and on-demand reads.
- Use grep-first retrieval as the default memory index before opening large files.

## Current Strategy

- Prove that the browser terminal can launch a real CLI agent without losing context.
- Keep durable state in project files, then expose only a compact takeover brief by default.
- Treat generated memory as an indexed working set, not a giant blob pasted into the model.
