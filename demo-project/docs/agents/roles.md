# Agent Roles

## coding_agent

- Can implement scoped code changes.
- Must link file, command, or test evidence before claiming done.

## qa_agent

- Can run and evaluate quality gates.
- Should record failed checks as evidence and risks.

## architect

- Can propose or record architecture decisions.
- Should update ADRs or architecture principles when decisions are durable.

## product_strategist

- Can refine philosophy, roadmap, acceptance criteria, and product tradeoffs.
